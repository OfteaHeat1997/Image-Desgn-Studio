## Contexto

¿Qué problema forzó esta decisión? ¿Qué restricciones había (presupuesto, tiempo, API de terceros, una sola desarrolladora)? Sin narrativa: hechos.

## Decisión

Qué se hace, en una o dos frases. En presente: *"Se usa X para Y"*, no *"se usará"*.

## Consecuencias

**Positivas:** qué gana el proyecto.

**Negativas / costo asumido:** qué se pierde o qué deuda se acepta. Un ADR sin consecuencias negativas casi siempre está incompleto.

## Evidencia

Fecha, medición, commit o log real. Si no hay evidencia medible, el estado debe ser `Propuesto`, no `Aceptado`.
